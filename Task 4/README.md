Project Title

Online Examination System using Java Swing

Description

The Online Examination System is a Java-based desktop application developed using Java Swing.
This project allows users to:

Login securely
Attend multiple-choice online exams
Navigate between questions
View score and percentage
Save exam results to a file
Change password using profile section

The application provides a timer-based examination environment with a colorful GUI interface.

Features
🔐 Login Authentication
User login validation
Default credentials:
Username: admin
Password: 1234
📝 Online Exam
Multiple-choice questions
Random question order
Previous and Next navigation
⏳ Timer System
60-second countdown timer
Auto-submit when time reaches zero
🎯 Score Calculation
Calculates:
Correct answers
Wrong answers
Percentage
💾 Result Storage
Saves result details into:
result.txt
👤 Profile Management
Change password functionality
🚪 Logout Feature
Logout and return to login page
