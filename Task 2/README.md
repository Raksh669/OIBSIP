Project Title

Guess The Number Game using Java Swing

Description

Guess The Number Game is a simple Java GUI application developed using Java Swing.
The player must guess a randomly generated number between 1 and 100 within a limited number of attempts.

The game provides:

Score calculation
Multiple rounds
Hint messages (Too High / Too Low)
Restart option
Interactive colorful GUI
Features
🎯 Random Number Generation
Generates a random number between 1 and 100 for every round.
🧠 Hint System
Displays:
Too High
Too Low
Correct Answer
🏆 Score System
Score increases based on remaining attempts.
🔄 Multiple Rounds
Automatically moves to the next round after winning.
❌ Game Over Detection
Ends the game after 10 wrong attempts.
🔁 Restart Option
Resets:
Score
Round
Attempts
🎨 Attractive GUI
Sky blue background
Styled buttons
Colored labels
User-friendly interface
Technologies Used
Java
Java Swing
AWT
Event Handling
Random Class
Timer Class
Components Used
Component	Purpose
JFrame	Main window
JPanel	Container panel
JLabel	Display messages
JTextField	User input
JButton	Buttons for actions
JOptionPane	Popup messages
Timer	Automatic round reset
Game Rules
The system generates a number between 1 and 100
Player has 10 attempts
After each guess:
Too High message appears
Too Low message appears
Correct answer gives score
Game ends after attempts become zero
