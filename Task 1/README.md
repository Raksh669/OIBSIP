Project Title

Online Reservation System using Java Swing

Description

The Online Reservation System is a Java-based desktop application developed using Java Swing for GUI components.
This project allows users to:

Login into the system
Reserve train tickets
View booked tickets
Cancel tickets using PNR number

The application stores reservation details temporarily using ArrayList and generates random PNR numbers for each booking.

Features
1. Login Authentication
Username and password validation
Default credentials:
Username: Rakshana
Password: admin
2. Train Reservation
Enter passenger details
Select train number
Auto-fetch train name
Choose class type
Enter journey date
Generate unique PNR automatically
3. Date Validation
Accepts only valid future dates
Prevents past date booking
4. View Reservations
Displays all bookings in table format using JTable
5. Cancel Reservation
Search reservation using PNR
Display reservation details
Cancel ticket successfully
